# Design system

The interface uses a dark, teal-accented token system defined in `src/admin/app/styles/base.css`.

- Backgrounds: `--bg`, `--surface`, `--panel`, and `--panel-strong`.
- Content: `--text` and `--muted`.
- Intent: `--accent`, `--success`, `--warning`, and `--danger`.
- Layout: `--space-1` through `--space-5` and three radius tokens.

Use shared panels, buttons, tables, form labels, dialogs, pagination, and responsive containers. Desktop two-column views collapse to one column below 900 px; multi-field forms collapse below 620 px.
